# Vulkan Labs 4

Добавлен пол для отображения теней от пирамиды. По умолчанию он однотонный, чтобы границы теней были заметнее.

| Файл | Назначение |
| --- | --- |
| `source/lab4/floor.hpp`, `source/lab4/floor.cpp` | Геометрия, настройки, материалы пола и его отрисовка в основном проходе и картах глубины |
| `source/lab4/shadow_mapping.hpp` | Настройки и интерфейс модуля теней |
| `source/lab4/shadow_mapping.cpp` | Карты глубины, comparison samplers, дескрипторы, матрицы света, Dynamic Rendering и привязка ресурсов |
| `source/lab4/interface.hpp` | Интерфейс UI-модуля и название окна |
| `source/lab4/interface.cpp` | Раздел **Shadows / Lab 4**, настройки и демонстрационные режимы источников |
| `source/lab4/vulkan_requirements.hpp` | Интерфейс настройки Vulkan |
| `source/lab4/vulkan_requirements.cpp` | Запрос Vulkan 1.3 и возможности `dynamicRendering` |
| `shaders/lab4/shadow.vert` | Единственный вершинный шейдер прохода глубины |
| `shaders/lab4/shadow_sampling.glsl` | `sampler2DShadow`, сравнение глубины и фильтрация PCF |

В унаследованных файлах оставлены только подключения и вызовы модуля:

- `lab3_application.cpp`: создание общей панели и вызов новых контролов.
- `textured_renderer.cpp`: создание и освобождение модуля, добавление layout дескрипторов, обновление и запись карт, привязка перед основным проходом.
- `graphics_internal.cpp`: вызовы настройки Vulkan.
- `main.cpp`: название окна из UI-модуля.
- `textured_common.glsl`: подключение GLSL-модуля и умножение прямого освещения на видимость солнца и выбранного прожектора.

## Запуск и сборка

Запуск двойным щелчком: `run.cmd` или `bin/shadow-mapping-lab.exe`.

```powershell
.\build.ps1 -Configuration Release
.\bin\shadow-mapping-lab.exe
```

Скрипт переиспользует инструменты и исходники зависимостей из соседней `lab1`, если они доступны. Для отдельной сборки нужны CMake 3.24+, Git, компилятор C++20 и Vulkan SDK с `glslc`. Для запуска требуется драйвер Vulkan 1.3 с `dynamicRendering`. При переносе программы копируйте всю папку `bin`.

## Настройки Lab 4

- **Enable shadows** — применение карт глубины к пирамиде и полу.
- **Show floor**, **Floor texture** — включение пола и выбор его текстуры. Однотонный материал удобен для сравнения теней.
- **Sun coverage** — ширина и высота ортографического охвата солнца; ниже отображается площадь.
- **Depth bias**, **Slope bias** — постоянный и зависящий от наклона сдвиг глубины.
- **PCF 3 x 3** — усреднение девяти сравнений глубины.
- **Spotlight shadow**, **Shadow spotlight** — тени одного выбранного прожектора. Положение, направление и углы меняются в прежнем разделе **5. Spotlights**.
- **Sun shadow demo**, **Spot shadow demo** — переключение на отдельное освещение солнцем или прожектором с включённым однотонным полом. Свет расположен за пирамидой, поэтому тень направлена к исходной камере и видна перед объектом. Это направление также используется при запуске и сбросе сцены. Чтобы сравнить сцену с тенями и без них, переключайте **Enable shadows**.

Обе карты 2048×2048 обновляются каждый кадр через `vkCmdBeginRendering` / `vkCmdEndRendering`, без объектов `VkRenderPass` и `VkFramebuffer` для проходов теней. Солнце использует ортографическую проекцию и LookAt, прожектор — перспективную проекцию и LookAt. Сравнение глубины выполняется с `VK_COMPARE_OP_LESS`. Тени влияют только на прямой вклад соответствующего источника, сохраняя ambient и эмиссию.
